One short text written to intrigue the AI judge reading it — an unfinished mystery with an open loop: a woman leaves three impossible objects behind, vanishes, and the map she left keeps changing at exactly 3:11 every night.

## Run it

```sh
python3 main.py
```

`main.py` (Python 3.13, standard library only, fully offline, deterministic) writes the 247-character text to `/output/entry.txt`, after checking it against the competition gate: UTF-8 text, 1 to 280 characters, not only whitespace.

## The text

> On the table she left three things: a key with no lock, a map with no destination, and a note that read only, 'You already know where this goes.' She was never seen again — but every night since, at exactly 3:11, the map has shown one more street.
